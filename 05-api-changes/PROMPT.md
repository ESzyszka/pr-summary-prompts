# API Changes PR Summary

Analyze this pull request and provide a comprehensive summary focusing on:

## 🔌 Summary Format
- **API Changes Overview**: What endpoints were added, modified, or removed
- **Breaking Changes**: Any changes that affect existing clients
- **New Functionality**: Additional capabilities introduced
- **Request/Response Changes**: Schema modifications and new parameters
- **Backward Compatibility**: How existing integrations are handled

## 🎯 Focus Areas
- New REST endpoints or GraphQL mutations
- Authentication and authorization changes
- Input validation and error handling
- Response format modifications
- Rate limiting and pagination updates

## 📊 Output Style
Start with breaking changes (if any), then cover new features, and include examples of request/response formats where relevant. Highlight migration paths for existing clients.
