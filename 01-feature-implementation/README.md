# Feature Implementation Templates

This folder contains CodeRabbit configuration templates and example code for feature implementation pull requests.

## Contents

- `coderabbit.yaml` - CodeRabbit configuration with feature-focused PR summary templates
- `auth-routes.js` - Example authentication route implementation
- `user-authentication.js` - User authentication service implementation

## Usage

Use these templates when creating pull requests that introduce new features to ensure comprehensive review coverage of:

- Core functionality implementation
- User experience considerations
- API design and integration
- Security implications
- Testing coverage

## Best Practices

- Include clear feature descriptions in PR titles
- Document new API endpoints and parameters
- Add unit tests for new functionality
- Consider backward compatibility
- Update relevant documentation
