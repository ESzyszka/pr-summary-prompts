# Bug Fix Templates

This folder contains CodeRabbit configuration templates and example code for bug fix pull requests.

## Contents

- `coderabbit.yaml` - CodeRabbit configuration with accessibility-focused PR summary templates
- `memory-leak-fix.js` - Example memory leak fix implementation

## Usage

Use these templates when creating pull requests that fix bugs to ensure comprehensive review coverage of:

- Root cause analysis
- Fix implementation details
- Regression testing
- Impact assessment
- Prevention strategies

## Best Practices

- Include clear bug description and reproduction steps
- Reference issue numbers in PR titles
- Add regression tests to prevent reoccurrence
- Document any breaking changes
- Consider performance implications of fixes

## Bug Fix Checklist

- [ ] Root cause identified and documented
- [ ] Fix addresses the core issue, not just symptoms
- [ ] Regression tests added
- [ ] Manual testing performed
- [ ] No unintended side effects introduced
